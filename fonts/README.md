# Bundled fonts

JetBrains Mono patched with [Nerd Fonts](https://www.nerdfonts.com) glyphs
(Regular, Bold, Italic, Bold Italic). `install.ps1` installs them for the
current user without a download, so it also works offline.

The fonts must not be sold on their own; bundling them with powershell10k is
allowed as long as these license files stay next to them.
